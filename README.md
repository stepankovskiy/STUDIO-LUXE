# Studio Luxe — готовый проект для Vercel

## Структура

- `index.html` — главная страница сайта.
- `assets/` — изображения страницы.
- `api/consultation.js` — серверная функция, отправляющая заявки в Telegram.

## Подготовка Telegram

1. Создайте бота через `@BotFather` и сохраните токен.
2. Создайте закрытую группу для заявок и добавьте в неё бота.
3. Отправьте в группе команду боту и получите `chat.id` через официальный метод `getUpdates`.
4. Не добавляйте токен и `chat_id` в GitHub.

## Развёртывание

1. Создайте новый репозиторий GitHub и загрузите в него содержимое этой папки.
2. Импортируйте репозиторий в Vercel.
3. Выберите Framework Preset: `Other`.
4. Не указывайте Build Command и Output Directory.
5. В `Project → Settings → Environment Variables` добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
6. Добавьте переменные минимум для окружений `Production` и `Preview`.
7. Выполните Redeploy после добавления или изменения переменных.

## Проверка

1. Откройте опубликованный сайт.
2. Отправьте тестовую заявку из каждой из трёх форм.
3. Убедитесь, что в Telegram отображаются источник формы и все заполненные поля.
4. Проверьте ошибку валидации, временно сняв обязательное подтверждение через инструменты браузера.

## Перед запуском

- Замените `example.ru` в `index.html` на реальный домен.
- Укажите рабочие ссылки на политику конфиденциальности вместо `href="#"`.
- Замените тестовые контактные данные и email.
- При появлении спама подключите Cloudflare Turnstile или другой серверно проверяемый CAPTCHA-механизм.

Файл `.env.example` содержит только названия переменных. Настоящие значения должны храниться в настройках Vercel.
